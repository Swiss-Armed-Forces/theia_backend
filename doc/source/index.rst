Theia
=====

Theia is an open source agent-based simulation framework for integrated air
defence (IAD), developed by the Swiss Armed Forces. It is used to assess the
consequences of an operational concept for sensors and effectors, compare
variants, and evaluate their performance against various hostile forces.

It is inspired by, and loosely based on, the open source code
`openBURST <https://github.com/Swiss-Armed-Forces/openburst>`_.

This documentation covers the ``theia`` backend: installation, running the
simulation server, and the concepts behind the physics and tracking models.
It is aimed at developers and product owners evaluating Theia — not at GUI
end users. If you are looking for the scenario editor or the live
visualisation frontend, see their respective repositories.
